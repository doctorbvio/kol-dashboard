# KOL 看板（种子体验官寄件流程）

一个纯静态的单页看板：把「种子体验官（KOL）寄件与素材交付」的十阶段流水线、
每台设备寄出前的硬性阻断规则、以及外部环境快照集中到一屏里。

- 线上地址：https://doctorbvio.github.io/kol-dashboard/
- 无后端：`index.html` 内嵌一份发布快照（`window.__KB_DATA__`），页面里的改动只写入**你这台浏览器**的
  localStorage，不会上传，也不会影响别人看到的版本。
- 「保存」= 存到本机浏览器；「重置为线上数据」= 清掉本机改动，回到发布快照。
- 需要多人共用同一份数据时，用「导出 CSV / 导入 CSV」交换，或把改动回填到 `data/published.json` 后重新发布。

## 数据状态

当前 **6 行全部是示例骨架**（人物字段为「待填」，只填了会触发规则的结构字段：波次 / 国家 / NDA / 自检），
用于验证看板与阻断逻辑。导入真实名单后请把 `meta.data_state` 改为 `live`。

## 阻断规则（把自检表的硬约束变成机器判据）

| 条件 | 级别 |
| --- | --- |
| Wave 2 国家 / 欧盟国家，且 CE（含 EN 18031）未通过 | 阻断 |
| 美国，且 FCC 未取得（进入寄件准备后） | 提示 |
| 对外发布口径日未定（进入寄件准备后） | 提示 |
| NDA / 素材授权未签（进入签约阶段后） | 阻断 |
| 单台档案缺城市 / 电脑 / 显示器接口（进入寄件准备后） | 提示 |
| 寄出前自检有「不通过项」 | 阻断 |
| 已寄出但自检未标「全部通过」，或缺设备序列号 | 提示 |
| 收件语言非中文（随箱指南当前只有中文版） | 提示 |

## 结构

```
index.html          单页（内嵌发布快照）
core.js             常量、状态、阻断规则引擎、localStorage 读写
render.js           看板 / 表格 / KPI / 外部环境渲染
ui.js               编辑抽屉、拖拽改阶段、CSV 导入导出
app.css             样式
data/published.json 发布快照（与 index.html 内嵌数据同源）
```
